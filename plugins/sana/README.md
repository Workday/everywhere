# Sana from Workday — Claude Code plugin

Use Sana in Claude to get answers and take action in Workday without switching tools. Employees can
check a time-off balance and submit a request in the same conversation, review pay information, find
a policy answer, file an expense, or review and approve supported transactions.

HR and finance self-service are available today. As admins enable more Workday agents and skills,
employees can handle broader and more complex work through the same plugin.

Sana uses only the Workday information each person is allowed to see. The same permissions, approval
chains, and business rules apply to every answer and action. When a task requires several agents or
tools, Sana coordinates them while the employee stays in Claude.

Your organization must have an active Workday Universal Main Subscription Agreement (UMSA) subject
to applicable Product Terms and the relevant Workday agents configured in the Agent Management Hub.
Available capabilities depend on your organization’s entitlements and configuration. Check Workday
Community for details.

The Sana from Workday connector is a Beta service. Workday admins can apply for access
[here](https://forms.gle/pz138pmAUE8x92B46).
